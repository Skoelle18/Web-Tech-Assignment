# Nikhil S Rao — Resume & Bio-data Website

## Pages
- `index.html` — Resume
- `biodata.html` — Bio-data
- `projects.html` — Projects and achievements
- `style.css` — Shared responsive styling
- `script.js` — jQuery/JavaScript interactions

## Features
- Semantic HTML5 elements
- Responsive CSS layout
- jQuery navigation and contact animation
- JavaScript dark/light theme with localStorage
- Mobile navigation menu
- External LinkedIn and GitHub links

## Host on GitHub Pages
1. Create a GitHub repository, e.g. `resume-website`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will publish the site at a URL similar to:
   `https://YOUR-USERNAME.github.io/resume-website/`

## Alternative cloud platforms
The same static files can also be deployed to Netlify, Vercel, or Cloudflare Pages by connecting the GitHub repository.
